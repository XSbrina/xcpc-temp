# XCPC C++ 算法模板

个人算法竞赛模板库，用于整理 XCPC 训练、刷题过程中常用的算法与数据结构，方便复习、查阅和使用。

所有模板存放于 [`c++/`](./c++/) 目录中，按算法名称命名。

## 模板目录

| 分类 | 主要内容 |
| :--- | :--- |
| 基础算法 | 二分、三分、分治、离散化、堆排序 |
| STL 与常用技巧 | `next_permutation`、`nth_element`、`__int128` 快读快写 |
| 数据结构 | 并查集、单调队列、ST 表、树状数组 |
| 线段树 | 普通线段树、区间乘、区间最值、权值线段树、主席树 |
| 最短路 | BFS、0-1 BFS、Dijkstra、Floyd |
| 最小生成树 | Prim、Kruskal、Kruskal 重构树 |
| 图的连通性 | Kosaraju、Tarjan 缩点、单向连通判断 |
| 网络流与匹配 | Dinic、最小费用最大流、二分图匹配 |
| 树上算法 | LCA、树的直径、树的重心、树的中心 |
| 动态规划 | 背包、数位 DP、状压 DP、矩阵快速幂优化 |
| 字符串 | KMP、Z 算法、随机双哈希 |
| 数学 | 快速幂、矩阵快速幂、欧拉函数、欧拉筛、埃氏筛、分数取模、线性基 |
| 计算几何 | 几何基础、凸包 |

具体文件见 [`c++/`](./c++/) 目录。

## 使用方法

1. 根据题目需要找到对应模板。
2. 阅读代码，确认下标、数据范围、参数和返回值的含义。
3. 将所需部分复制到解题代码中，结合题目调整后使用。

使用时重点检查：

- 数组大小与内存占用。
- 无穷大、取模常量等设置是否合适。
- 多组测试时是否正确清空数组和容器。
- 模板所需的前提条件是否满足。
